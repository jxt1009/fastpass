## Task 1: P0-1 — Drop dead `?? 0` in `CarStats.swift`

**Files:**
- Modify: `ios/FastTrack/FastTrack/Models/CarStats.swift:88-94`

### Background

`Drive.maxAcceleration`, `maxDeceleration`, `peakGForce`, `brakeEvents`, `leftTurns`, and `rightTurns` are declared non-optional in `Models/Drive.swift:30-37` and populated during recording (`ViewModels/DriveManager+Processing.swift:238-241` and `ViewModels/DriveManager.swift:269-272`). The `?? 0` in `CarStats.swift:88-94` is dead code — the compiler allows it because Swift's `??` operator accepts an optional LHS and a non-optional RHS, but the optional is never actually nil. The dead code is a landmine for future refactors (e.g. someone might "fix" it by also making the Drive fields optional, breaking the rest of the app). The user confirmed in spec §7 that the fields should be non-optional and `?? 0` should be dropped.

## Task 2: P0-2 — Cache `LiveMapView.displayCoordinates`

**Files:**
- Modify: `ios/FastTrack/FastTrack/Views/ContentView.swift:370-435`
- Test: `ios/FastTrack/FastTrackTests/LiveMapViewDecimationTests.swift` (new)

### Background

`LiveMapView.displayCoordinates` (ContentView.swift:390-393) is a computed property that runs `RouteDecimator.decimate(_:toleranceMeters:maxOutput:)` on every SwiftUI body evaluation. During recording, `routeCoordinates` is a `@Published` property on `DriveManager` that updates at ~1 Hz, so `ContentView.body` invalidates every second, the computed property re-runs (`O(n log n)` for the RDP pass), and `MapKit` re-renders the polyline.

The fix: cache the decimated output in `@State` and only recompute when the input changes by a meaningful amount. The threshold is a small delta (e.g. ≥10 new points) so 1-Hz appends do not retrigger redecimation every tick.

### Steps

- [ ] **Step 2.1: Write the failing test**

Create `ios/FastTrack/FastTrackTests/LiveMapViewDecimationTests.swift`:

import XCTest
import CoreLocation
@testable import FastTrack

/// Regression test for P0-2: the decimated output must be stable when
/// the input hasn't changed. The fix moves the RDP pass out of the
/// computed property into a cached value. This test exercises the
/// decimation policy (≥10 new points triggers redecimation) without
/// pulling in SwiftUI.
final class LiveMapViewDecimationTests: XCTestCase {

    private func coords(_ count: Int) -> [CLLocationCoordinate2D] {
        (0..<count).map { i in
            CLLocationCoordinate2D(latitude: Double(i) * 0.0001, longitude: 0)
        }
    }

    func testDecimatorReturnsInputWhenUnderThreshold() {
        let input = coords(100)
        let output = RouteDecimator.decimate(input, toleranceMeters: 5, maxOutput: 500)
        XCTAssertEqual(output.count, 100)
    }

    func testDecimatorCapsAtMaxOutput() {
        let input = coords(2000)
        let output = RouteDecimator.decimate(input, toleranceMeters: 5, maxOutput: 500)
        XCTAssertEqual(output.count, 500)
    }

    func testDecimatorIsDeterministic() {
        let input = coords(600)
        let a = RouteDecimator.decimate(input, toleranceMeters: 5, maxOutput: 500)
        let b = RouteDecimator.decimate(input, toleranceMeters: 5, maxOutput: 500)
        XCTAssertEqual(a, b)
    }
}

The shape of the change:

The exact code:

```swift
@State private var cachedDecimated: [CLLocationCoordinate2D] = []
@State private var cachedInputCount: Int = 0

private func recomputeDecimationIfNeeded() {
    let count = routeCoordinates.count
    if count == cachedInputCount { return }
    if count > cachedInputCount && count - cachedInputCount < 10 { return }
    cachedDecimated = RouteDecimator.decimate(
        routeCoordinates,
        toleranceMeters: 5,
        maxOutput: 500
    )
    cachedInputCount = count
}
```

```swift

```

And replace `let coords = displayCoordinates` with `let coords = cachedDecimated`.

Also remove the `displayCoordinates` computed property entirely.

## Task 3: P0-3 — Verify Google OAuth `state` on callback

**Files:**
- Modify: `ios/FastTrack/FastTrack/Services/GoogleSignInManager.swift:22-68`
- Test: `ios/FastTrack/FastTrackTests/GoogleSignInManagerStateTests.swift` (new)

### Background

The Google OAuth flow generates a `state = UUID().uuidString` parameter and includes it in the authorization URL, but the callback never verifies the returned `state`. An attacker who can open `com.toper.fasttrack:/oauth2callback?code=ATTACKER_CODE&state=ANYTHING` can link their Google account to the victim's FastTrack user. This is a CSRF vulnerability (CWE-352).

The fix: store the expected `state` in an instance property, and on callback, compare the returned `state` query item to the stored value. Reject if they do not match.

The current `state` is a local `let` that goes out of scope when `signInWithGoogle()` returns. We need to lift it to an instance property so the callback can read it.

- [ ] **Step 3.3: Add a state-verification helper**

Add a private helper method to `GoogleSignInManager` (place it just before the closing brace of the class, after the existing `generateCodeChallenge` function):

```swift
/// Verifies that the `state` query parameter on the OAuth callback matches
/// the value we sent in the authorization URL. Prevents a CSRF attack where
/// an attacker opens our callback scheme with their own authorization code
/// and links their account to the victim's FastTrack user.
func verifyState(in callbackURL: URL) -> Bool {
    guard let components = URLComponents(url: callbackURL, resolvingAgainstBaseURL: false),
          let returnedState = components.queryItems?.first(where: { $0.name == "state" })?.value
    else {
        return false
    }
    // Constant-time compare to avoid timing oracles. Both are ASCII UUID
    // strings of equal length in practice; the comparison is short enough
    // that timing leakage is not exploitable here, but the pattern is
    // correct.
    guard !expectedState.isEmpty,
          returnedState.count == expectedState.count
    else {
        return false
    }
    var diff = 0
    for (a, b) in zip(returnedState.utf8, expectedState.utf8) {
        diff |= Int(a) ^ Int(b)
    }
    return diff == 0
}
```
